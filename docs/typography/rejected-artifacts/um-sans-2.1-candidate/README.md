# UM Sans 2.1 Rejected Candidate

Rejected after human raster review on 2026-07-16. The WOFF2 file is retained
only as evidence of the failed drawing experiment.

- Approved use: none.
- Failure: malformed lowercase rhythm, inconsistent joins and poor word texture.
- Prohibited use: specimen, localhost preview, production, body copy, UI,
  resale or public font delivery.
- Stable fallback: UM Sans Text 1.2.
- Replacement rule: a complete redraw must pass mobile and desktop word-level
  screenshots before it can be registered by the website CSS.
