# Support and versioning

Family: UM Sans
Release: 1.2 Production
Vendor: ULTIMA MILLA S.A.
Web: https://www.ultimamilla.com.ar
Specimen: https://www.ultimamilla.com.ar/estilo/um-sans

When reporting a problem include the font filename, application and version,
operating system, text sample, OpenType features, point size and screenshot.

The 1.x line remains an OFL derivative of Inter 4.001. Font versions use
OpenType `fontRevision` and name ID 5. File replacement without a version bump
is prohibited.
