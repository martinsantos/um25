# Family naming and style linking

## Public names

- Typographic family: `UM Sans`
- Full version: `Version 1.200`
- Variable styles: `UM Sans Variable` and `UM Sans Variable Italic`
- CSS family: `UM Sans`
- Trademark owner: ULTIMA MILLA S.A.

## Static matrix

The family contains Thin, ExtraLight, Light, Regular, Medium, SemiBold, Bold,
ExtraBold and Black in Roman and genuine Italic. Modern applications read the
typographic family records. Legacy applications receive linked Regular,
Italic, Bold and Bold Italic identities; non-RIBBI weights retain compatible
legacy subfamily names.

## Rules

- Do not rename binaries without rebuilding every OpenType name record.
- Do not install OTF and TTF copies at the same time.
- Do not synthesize bold or italic.
- Futura PT remains restricted to the ULTIMA MILLA wordmark.
- A future independently drawn `UM Sans 2.0` must use a new version and must
  not overwrite 1.x until document reflow has been approved.
