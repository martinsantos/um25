# Known issues and release limits

UM Sans 1.2 has no blocking FontBakery, structural, shaping, raster, install or
PDF-embedding result. The current FontBakery run records 58 warnings inherited
from or introduced around modified upstream contours and interpolation. They are
reviewable debt, not hidden certification.

## Open validation

- physical Windows DirectWrite and Microsoft Office proof;
- Adobe InDesign/Illustrator and PDF/X preflight;
- Safari on current macOS and physical iOS hardware;
- physical Android raster and fallback behavior;
- offset/digital press proof signed by the operator;
- independent similarity, trademark and authorship review for UM Sans 2.0.

## Deliberate limits

- no Cyrillic, Greek, Arabic, Hebrew, CJK or emoji claim;
- no DRM, activation portal or proprietary EULA;
- no claim that the 1.x base skeleton was drawn independently;
- no WOFF1, EOT or legacy web format where WOFF2 is supported.
