# Print and PDF guide

The release gate produces a 20-page PDF and verifies that both the roman and
italic UM Sans variable fonts are embedded without accidental Poppins, Open Sans
or Arial substitution.

## Export checklist

- embed fonts or create a final outlined copy only after editorial approval;
- preserve live-text source files for corrections and accessibility;
- use tabular figures for tables, dates, prices and SLA;
- inspect the PDF font list before delivery;
- run the printer's PDF/X profile when a press standard is required;
- proof small text, reversed text and heavy display weights on the target device.

Browser PDF embedding is verified. Offset, digital press and application-specific
preflight remain external until a dated physical proof is attached to the release.
