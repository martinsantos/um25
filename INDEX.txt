SCRIPTS DE EJECUCIÓN
────────────────────
fix_articles.sh
  Script bash que:
  - Descarga el payload JSON de cada artículo vía curl
  - Aplica reescrituras usando jq (preserva estructura JSON)
  - Persiste cambios con PATCH a Directus API
  - Implementa fallback: si PATCH falla, intenta DELETE+POST
  - Rate limiting: 0.3s entre llamadas
  - Genera log de ejecución

  Requisitos previos:
  - jq instalado (procesar JSON)
  - curl instalado
  - Variable $DIRECTUS_TOKEN configurada O credenciales base64

  Ejecución:
    export DIRECTUS_TOKEN="tu_token_o_credenciales"
    bash fix_articles.sh

fix_interactive.sh
  Script bash que:
  - Mismo flujo que fix_articles.sh
  - Añade pausas y menús interactivos
  - Colores para legibilidad
  - Confirmación antes de cada persistencia
  - Progress bar para descarga/procesamiento

  Uso: Ideal para primera ejecución o verificación manual
  Ejecución:
    bash fix_interactive.sh

COMANDOS_RAPIDOS.sh
  Archivo que contiene:
  - Comandos curl listos para copy-paste
  - Un comando por reescritura
  - Organizados por artículo
  - Incluye autenticación base64 inline

  Uso: Para ejecución manual o debugging individual

⚠️ TROUBLESHOOTING RÁPIDO
─────────────────────────────────────────────────────────────────────────────

Problema: "command not found: jq"
Solución:
  macOS: brew install jq
  Linux: apt-get install jq
  Windows: Descargar de https://stedolan.github.io/jq/

Problema: "HTTP 401 Unauthorized"
Solución:
  - Verificar DIRECTUS_TOKEN válido
  - Verificar que no expiró (< 24h de antigüedad)
  - Regenerar token en Directus Admin si es necesario

Problema: "HTTP 301 Moved Permanently"
Solución:
  - Los scripts ya incluyen -L para seguir redirects
  - Si usas curl manual, añade -L al comando

Problema: "jq: parse error"
Solución:
  - Verificar JSON válido: curl | jq '.' primero
  - Posible issue de encoding UTF-8
  - Ver sección JSON en README_TERMINAL.md

Problema: "PATCH/POST retorna 400 Bad Request"
Solución:
  - Verificar que JSON es válido (jq '.' primero)
  - Verificar que el slug es correcto
  - Revisar correccion_fallidas.md para detalles

Para más detalles, véase: README_TERMINAL.md (sección TROUBLESHOOTING)
