⚠️ Regla crítica de contraste

Nunca usar texto NEGRO sobre fondo ROJO para cuerpo de texto (ratio 4.3:1 falla WCAG AA normal). Sobre ROJO usar siempre BLANC (ratio 4.9:1 ✅). Esta regla aplica a todos los formatos.

Sistema de espaciado

10 unidades (0–9), base 5px. Inspirado en la escala GOV.UK. Prohibido usar valores arbitrarios fuera de esta escala.

SP0
0px · 0 DXA — sin espaciado
SP1
5px · 100 DXA — párrafos en celdas de tabla
SP2
10px · 200 DXA — espacio mínimo post-run
SP3
15px · 280 DXA — separación entre runs
SP4
20px · 400 DXA — estándar entre párrafos (Regla 3)
SP5
25px · 500 DXA — antes de cuerpo post-cabecera
SP6
30px · 600 DXA — antes de sección H2
SP7
40px · 800 DXA — pre-sección con page break
SP8
50px · 1000 DXA — entre bloques mayores
SP9
60px · 1200 DXA — post-encabezado, pre-firma

// Escala de espaciado UMSA — array canónico
const SP = [0, 100, 200, 280, 400, 500, 600, 800, 1000, 1200];

Componente sec() — sección numerada

JavaScript
function sec(num, titulo, pb = false) {
  const items = [];
  if (!pb) {
    items.push(new Paragraph({ spacing: { before: SP[4], after: 0 }, children: [] }));
  } else {
    items.push(new Paragraph({ spacing: sp(0,0), children: [new PageBreak()] }));
  }
  items.push(new Paragraph({
    border: { bottom: { style: BorderStyle.SINGLE, size: 8, color: ROJO, space: 4 } },
    spacing: sp(0, SP[3]),
    children: [
      new TextRun({    // Badge azul — TextRun.shading, NO tabla (Regla 7)
        text: '\u00A0' + num + '\u00A0',
        font: F_HEAD, size: SZ.h2, bold: true, color: BLANC,
        shading: { type: ShadingType.CLEAR, fill: AZUL }
      }),
      new TextRun({
        text: '\u2002\u2002' + titulo.toUpperCase(),
        font: F_HEAD, size: SZ.h2, bold: true, color: NEGRO
      })
    ]
  }));
  return items;
}

Reglas críticas

Resultado de errores reales detectados en producción. Todas son obligatorias en todos los formatos.

1Columna numérica ≥ 1700 DXA
La columna de importes ARS nunca puede ser < 1700 DXA. "$ 12.939.000" en Arial 10pt necesita ~1730 DXA mínimo. Usar W_MONTO = 2000 como valor seguro.
2Sin colores fuera de paleta
Prohibido: #FFF3F3 (rosa), #1a3a6b (marino), #f0f4fb (azul claro). Fondo alterno oficial: solo #F5F5F5.
3Aire antes de secciones
Todo encabezado de sección necesita spacing.before = SP[4] = 400 DXA como mínimo. Implementar con párrafo vacío previo en sec().
4Page breaks en sección ≥ 3
Secciones 3, 4, 5+ deben comenzar en página propia. Usar sec(3,'Título', true) — el parámetro pb=true inserta new PageBreak().
5Body mínimo 12pt (24hp)
El texto de cuerpo nunca puede ser < 12pt. En DOCX: size: 24 mínimo. Celdas de tabla: size: 20 (10pt) como excepción permitida.
6ROJO nunca como fill de celda
LibreOffice puede ignorar el color de TextRun sobre fondo ROJO → texto negro ilegible. ROJO solo como borde, línea, texto o acento. Fondo oscuro: usar NEGRO.
7Secciones como Paragraph, no tabla
Tablas con ShadingType.CLEAR en LibreOffice heredan el tema de color → tinte rosa/cálido. Badge de sección: usar TextRun.shading dentro de un Paragraph.
8Separadores en filaCab
En cabecera NEGRO, los bordes NEGRO son invisibles. Usar color: '555555' en el borde izquierdo de las columnas 2..N de la cabecera.
9\n no genera salto de línea
En DOCX, el salto de línea es <w:br/>, no \n. Hacer split('\n') y crear un Paragraph por línea en tcMulti().
10cantSplit en filas de datos
Todas las filas de tabla con >1 línea deben tener cantSplit: true. Una fila partida entre páginas es ilegible. Excepción: filas > 2/3 del alto de página.
11gridMeta label ≥ 1600 DXA
"DESTINATARIO" en Arial 9pt necesita mínimo 1600 DXA. Con menos, se quiebra como "DESTINATAR / IO". Par label+valor: 1600 + 2913 = 4513 DXA.
!WCAG: BLANC sobre ROJO siempre
NEGRO/ROJO = 4.3:1 → falla WCAG AA para texto normal. Texto sobre fondo ROJO siempre en BLANC (4.9:1 ✅). Sin excepciones para cuerpo de texto.
