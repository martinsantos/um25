# UM Sans 2 Display: prototipo bloqueado

Este experimento procedural no es una fuente aprobada. La revisión visual de
palabras completas detectó contornos deformes, ritmo irregular y signos
inconsistentes. Sus binarios se conservan únicamente como evidencia técnica y
no deben cargarse, distribuirse ni utilizarse en interfaces o documentos.

- `specimen.html`: aviso portátil de cuarentena; no carga los binarios.
- `build-report.json`: inventario y estado de promoción.
- `qa-report.json`: se genera con `npm run fonts:audit:um-sans-2-display`.
- `PROVENANCE.md`: procedencia y límites de distribución.
- `CHECKSUMS.sha256`: integridad de los binarios.

El estado vigente es `structural-pass / visual-fail`. Un futuro UM Sans Display
requiere redibujo profesional completo y una nueva revisión visual
independiente; estos archivos no constituyen una base publicable.
