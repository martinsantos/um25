# UM Sans 2 Display: build bloqueada

Los binarios de este directorio conservan una prueba de construcción original,
pero no están aprobados para la web, documentos ni distribución.

La auditoría visual de palabras, repertorio español y pantallas responsive
detectó deformaciones repetidas en glifos y uniones. Las comprobaciones
estructurales de OpenType, cobertura, métricas y hinting habían pasado, pero no
son una validación de calidad de dibujo.

## Reingreso

El corte solo puede volver al sistema después de:

1. redibujar el repertorio base completo;
2. rasterizar palabras, alfabeto, acentos, signos y cifras en cada peso;
3. aprobar pruebas desktop, mobile y documentos;
4. completar revisión independiente de similitud, marca y procedencia.

Hasta entonces, el sistema público usa exclusivamente UM Sans Text 1.2.
